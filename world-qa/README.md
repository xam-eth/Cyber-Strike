# Stellar Horizon — World QA (Godot 4.6.2)

**Independent Godot project — no game, only world.** Open and explore the STELLAR HORIZON floating-archipelago without any player controls; the camera tours automatically.

> **Role:** World Designer only — this project is the deliverable for world design (level-design + camera-systems + create-game-assets). No gameplay, no clone of whole game.

## Quick Start (Godot)

**Option A — GUI:** Install [Godot 4.6.2](https://godotengine.org/download) → **Import** → select `world-qa/project.godot` → **Play (F5)**

**Option B — Headless (sandbox):**
```bash
tools/.cache/godot --path world-qa --import   # first time: imports 4 GLBs
tools/.cache/godot --path world-qa            # runs cinematic tour
# or bundled:
./tools/.cache/godot --version  # 4.6.2.stable.official.71f334935
```

Expected: `World QA: loaded frostline` + smooth cinematic tour through 8 viewpoints (overview → tower → platform → canyon → interior → bridge → island → rim). No input required.

## Controls (optional, not required)

- **SPACE** — toggle **CINEMATIC** (auto tour, *tanpa controll*) ↔ **ORBIT** (manual)
- **N / P** — next / prev world (same geometry, different mood)
- **1 2 3 4** — jump to frostline (DAY) / verdant (SUNSET) / emberfall (NIGHT) / titans (STORM)
- **Right-drag** — orbit (only in ORBIT mode, uses `screen_relative`, clamped pitch -72°..51°)
- **Scroll** — zoom (orbit)
- **WASD / Q E** — pan target (orbit)
- **R** — recenter orbit

Default is **CINEMATIC**: hands-free, frame-rate independent (`1 - exp(-rate*dt)`), eased with smoothstep, late-update, respects world bounds (180×180).

## World — ONE WORLD / MANY BATTLES

Same 180×180 geometry for all 4 moods; only sky/fog/lights change (foto ref: Environment & Mood 4 panels).

- **Metrics (level-design):** 180×180, 12 roads, 30 shared placements, tower hub 28m beam, 6 islands y+6-11, 4 bridges y+6, 4 canyon walls, 2 interior bases, 8 cover every 5-6m, 5 enemy gates, 4 turrets. Critical path: **canyon → tower → platform → interior** (golden path + secondary dashed + outer loop).
- **Moods:**
  - `frostline` — DAYTIME (`#87c4ea`, sun `fff7e0`, tower rim `59e6ff`)
  - `verdant` — SUNSET (`#ff8c52`, warm fill `ff9a5a`)
  - `emberfall` — NIGHT (`#1a2a4a`, city fill `59e6ff`, interior `2a6aff`)
  - `titans` — STORM (`#3a4a5a`, grey haze)
- **Components:** GLB real (Kenney space-kit, ground tile, powerplant 42M, nature) — no procedural geometry. Cable dual-state intact / broken+spark, broken via Blender abstract fracture, buildings per-asset.
- **Files:** `assets/worlds/*.glb` (~5 MB each, 95-105k tris, gz 3-4M), generated by `tools/asset-forge/src/worlds/` (THREE.js → GLB, provenance `userData.realSource`).

## Godot Project Layout

```
world-qa/
  project.godot          # 4.6, gl_compatibility, Canvas stretch
  assets/world_env.tres  # fog + glow + ambient (cinematic)
  assets/worlds/*.glb    # 4 moods, same graph
  scenes/world_viewer.tscn  # WorldHolder + Camera + UI
  scripts/world_viewer.gd       # orchestrator, 8-viewpoint tour, mode toggle
  scripts/cinematic_camera.gd   # exponential smoothing, smoothstep, late update
  scripts/orbit_camera.gd       # yaw/pitch clamp, screen_relative, bounds, SpringArm hook
```

**Disciplines applied** (from [awesome-gamedev-agent-skills/disciplines](https://github.com/gamedev-skills/awesome-gamedev-agent-skills/tree/main/skills/disciplines)):
- `level-design` — metrics, blockout→dress, critical/golden path, pacing curve, gating, readability
- `camera-systems` — 2D/3D follow, deadzone, look-ahead, bounds clamp, 3D orbit+collision+clamped pitch, shake hook, frame-rate independent
- `create-game-assets`, `procedural-gen`, `performance-optimization`, `shader-programming` (supporting)

See `.claude/skills/level-design/SKILL.md` and `camera-systems/SKILL.md` for patterns (installed in branch).

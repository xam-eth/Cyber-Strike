## Current development boundary

The current implementation slice is the NEON FRONTIER connected procedural 3D world plus third-person movement/camera, camera-center aiming, training target, deterministic Runner/Shooter waves, Pulse/Nova/Arc weapons, EMP skill, and mobile HUD/controls. World components remain distinct 3D scenes; selected KayKit props are GLTF resources exposed through static `PackedScene` preloads for export dependency scanning. Ten Kenney Space Kit CC0 GLBs are now downloaded with pinned source/license provenance for review; they are candidates only and are not yet used in scenes. Smoke scripts cover world/traversal, combat, rewards, waves, joystick directions, HUD, and EMP, but the latest set has not been run in Godot in this session. Historical metrics from an earlier headless checkout are not current verification. Android import/export support is scaffolded in `scripts/export_android_debug.sh`; the local preset, APK export, device test, rendered appearance, mobile performance, enemy navigation, and balance remain unverified. Run-scoped `RunStats`/`RewardService` records Runner/Shooter eliminations, Run Score, BP earned, and survival time; the Results/retry overlay reads those values. Persistent BP wallet, unlock/equip, save, and final production art are not implemented. It is **not** the completed MVP loop.

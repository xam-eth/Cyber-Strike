# Direction reference — Aetherfall dense sci-fi arena

This is a **design-analysis reference only**. No external image, mesh, texture,
logo, or branded asset has been copied into the project.

## References reviewed

- [Sci-Fi Spaceship Hangar / Learte Studios](https://www.fab.com/listings/e56926ea-a37c-40b6-8312-4930a0fba4ac?lang=en) — overhead pipes, suspended maintenance mass, layered depth.
- [Sci-Fi Industrial Base](https://www.fab.com/listings/330d84e7-1f1d-4289-95d8-d2ac44940b39) — clear bright exit, dark foreground frame, stacked decks.
- [SciFi Level Hangar and Corridor Kit](https://fab.com/listings/6079b169-9235-4a4f-8a28-9ee814bd4243) — readable industrial façade vocabulary: tanks, exterior stairs, rails, pipe bundles and vertical service shafts.

## Translation for Aetherfall

The world should not read as an empty rectangular deck with isolated props. The
usable visual grammar is:

1. **Three scales at every vista:** foreground service object, mid-ground
   building/cover, and tall background silhouette.
2. **Vertical rhythm:** towers, stacked machinery, gantries, overhead services
   and raised platforms break the continuous zero-height deck.
3. **Functional density:** cargo exists near hangars, receiver infrastructure
   around relays, and operations hardware near arrivals; no unmotivated crates.
4. **Lighting hierarchy:** cyan operational guidance, sparse amber hazard
   accents, and one brighter depth target; bloom must not erase edge detail.
5. **QA framing, not a placeholder avatar:** the default scene uses a camera
   with presets for overview, outpost, cache/route, relay, hangar, density, and
   tower. This is the correct route for visual review of a standalone world.

The next structural pass should concentrate on connected multi-level industrial
massing and overhead/raised infrastructure rather than adding scattered small
props.

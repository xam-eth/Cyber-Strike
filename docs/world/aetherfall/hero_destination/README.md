# Hero Destination — Gate 01 working set

**Scope:** the seven assets selected for the first real production batch:

1. Sentinel Archive exterior
2. Archive Vestibule
3. Archive Computer
4. Energy Core
5. Tower Foundation
6. Tower Tier
7. Tower Spire

The documents in this directory are **draft production briefs**, not an acceptance stamp and not an authorization to start Retopology, UV, bake, PBR, or export. They turn the prior world-level concept into asset-specific modelling instructions, using the current runtime GLB only as a measured legacy envelope and placement baseline.

`reference/` now contains seven original, asset-specific concept studies and a hash manifest. ## Android baseline selected — device profile still required

Android is the selected platform baseline. No actual mobile triangle, texture, material, draw-call, or memory number is entered here because a target device tier, resolution/render scale, frame-rate goal, renderer, and test build are not yet recorded. Inventing an “industry-standard” number would be less rigorous than leaving it unresolved. Those values become mandatory before an `LP_` budget or optimization decision.

## Shared reference rules

- `../reference/01_archive_hero.png` is the original world-language study: destination hierarchy, cold robot architecture, deeply recessed threshold, ice-to-structure contact, and distant industrial scale. It is **not** a texture, decal, bake, or a license to copy an existing building.
- The existing GLB envelopes are measurements of a legacy asset. They are not approved final proportions.
- The current project has a camera-only review route and no accepted player/avatar scale. Every brief therefore has a **scale blocker**: place an approved player/camera proxy at the real approach route before Gate 01 is accepted.
- Front/side/top text in the brief is an equivalent modelling turnaround: it specifies the silhouette and functional volume arrangement that must be drawn and then visually reviewed in Blender. It does not substitute for an asset render.

## Gate 01 exit rule for this batch

Every document needs a director/technical-art review of its brief, functional-volume map, scale proxy, and orthographic guide. Only then can that **individual asset** start Base Mesh. The entire bundle does not advance as one opaque “hero asset.”

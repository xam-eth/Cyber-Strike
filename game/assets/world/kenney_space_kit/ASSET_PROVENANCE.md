## Import/use gate

These are actual downloaded 3D GLB models, not generated screenshots or replacement 2D images. Before scene use, open/import them in Godot 4.7.2, inspect scale/orientation/materials, and choose exact placements. Then add only selected files to the static resource map and smoke-test the 3D scene; unused candidates should not be forced into the Android PCK. Current sandbox lacks Godot, so engine import, in-scene appearance, and Android packaging remain unverified.
